## 📌 Project Overview
This repository brings together three foundational web development assignments completed as part of the Oasis Infobyte internship curriculum. The project emphasizes responsive layout architecture, modern dark-mode aesthetic styling, and vanilla JavaScript DOM manipulation without external framework overhead.

---

## 🚀 Tasks Breakdown

### 🎯 Task 1: Responsive Landing Page (`landing_page.html`)
* **Objective**: Design and build an engaging, modern landing page with a clear visual hierarchy.
* **Key Features**:
  * Hero banner with clear call-to-action (CTA) pointing to the developer portfolio.
  * Multi-column feature highlights showcasing services, skills, and core value propositions.
  * Semantic HTML structure (`header`, `main`, `section`, `footer`).
  * Custom dark-themed CSS styling with responsive breakpoints for desktop, tablet, and mobile screens.

### 💼 Task 2: Personal Developer Portfolio (`portfolio.html`)
* **Objective**: Create a comprehensive personal brand portfolio presenting developer identity, capabilities, and contact points.
* **Key Features**:
  * Personal biography and professional summary.
  * Interactive skills matrix highlighting technical proficiencies.
  * Curated projects gallery with descriptions and external links.
  * Direct contact form and social connection channels.

### 🌡️ Task 3: Interactive Temperature Converter (`portfolio.html` + `converter.js`)
* **Objective**: Build a real-time mathematical conversion tool between global temperature measurement standards.
* **Key Features**:
  * Bidirectional conversion between **Celsius (°C)**, **Fahrenheit (°F)**, and **Kelvin (K)**.
  * Real-time input sanitization ensuring non-numeric entries are prevented.
  * Clean output formatting with exact unit labels and dynamic result calculation.
  * Formulated via standard thermodynamic relationships:
    $$\text{°F} = (\text{°C} \times \frac{9}{5}) + 32$$
    $$\text{K} = \text{°C} + 273.15$$

## 🛠️ Technologies Used
* **HTML5**: Semantic web architecture and accessibility.
* **CSS3**: Custom dark theme, flexbox, CSS grid, media queries, and transition animations.
* **JavaScript (ES6+)**: Event listeners, dynamic DOM manipulation, and conversion algorithms.
